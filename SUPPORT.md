# Support

## Getting Help

- Usage questions and troubleshooting: start a [GitHub Discussion](https://github.com/Ankit-Cherian/steno/discussions).
- Bug reports: use the `Bug Report` issue template.
- Feature requests: use the `Feature Request` issue template.

Steno has one maintainer, so replies can take a while.

## Reporting a Problem

Use the [latest release](https://github.com/Ankit-Cherian/steno/releases/latest) when reporting a problem. Older releases are no longer supported once a replacement is published. For source builds, include the commit as well as the app version.

Include:

- your macOS version
- the Steno version and build, shown in Settings › General (for example, Steno 1.1.0 (5))
- the speech model selected in Settings › Speech Model
- how you started the recording: Hold Option, the hands-free key, or the Dictate area in the main window
- whether Show live transcript was on
- the approximate recording duration
- the exact error or what you saw

Say whether the problem affected the live transcript, the final text, insertion, or History.

For an apparent timeout, note when it happened and whether a later recording worked. Share only relevant, redacted details. Do not attach recordings, transcripts with personal content, surrounding editor text, or raw system logs to a public issue.

## Security Issues

For potential vulnerabilities, follow [the security policy](SECURITY.md) and use private reporting when possible.
