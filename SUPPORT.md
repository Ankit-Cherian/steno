# Support

## Getting Help

- Usage questions and troubleshooting: open a GitHub Discussion or Issue.
- Bug reports: use the `Bug Report` issue template.
- Feature requests: use the `Feature Request` issue template.

## Reporting a Problem

Use the [latest release](https://github.com/Ankit-Cherian/steno/releases/latest) when reporting a problem. Older releases are no longer supported once a replacement is published. For source builds, include the commit as well as the app version. Include the app version/build, macOS version, model, recording mode, whether live preview was enabled, approximate recording duration, and the exact error or visible result. State whether the issue affected the live preview, completed transcript, insertion, or recovery/history.

For an apparent timeout, note when it occurred and whether another recording succeeded. Preserve diagnostics before changing settings or restarting. Share only relevant, redacted details. Don’t post private transcripts, surrounding editor text, audio, or raw system logs in a public issue.

## Security Issues

For potential vulnerabilities, follow [the security policy](SECURITY.md) and use private reporting when possible.
