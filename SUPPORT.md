# Support

## Getting Help

- Usage questions and troubleshooting: open a GitHub Discussion or Issue.
- Bug reports: use the `Bug report` issue template.
- Feature requests: use the `Feature request` issue template.

## Reporting a 1.0 Candidate Problem

The 1.0 candidate is still under testing; the public v0.2.0 download is a different build. Include the app version/build, macOS version, model, recording mode, whether live preview was enabled, approximate recording duration, and the exact error or visible result. State whether the issue affected the live preview, completed transcript, insertion, or recovery/history.

For an apparent timeout, note when it occurred and whether another recording succeeded. Preserve diagnostics before changing settings or restarting. Share only relevant, redacted details; do not post private transcripts, surrounding editor text, audio, or raw system logs in a public issue.

## Security Issues

For potential vulnerabilities, follow `SECURITY.md` and use private reporting when possible.
